### 1. [Wazuh Mini SOC Lab — Windows Endpoint Detection & Incident Triage](https://github.com/shettysanket06/wazuh-mini-soc-lab)

A hands-on Wazuh SIEM home lab with an Ubuntu Server manager and a Windows endpoint. The work covers Windows Security, Sysmon and PowerShell telemetry, custom detections, FIM, SCA, vulnerability inventory review, alert triage, and evidence-based incident reporting.

**Highlights**
- Validated custom detections and built-in Wazuh alerts using controlled endpoint activity.
- Tested Windows event collection, File Integrity Monitoring, and endpoint onboarding.
- Documented detection limitations and a misleading MITRE ATT&CK mapping rather than overstating findings.
- Produced four investigation reports, all assessed as benign, authorized lab activity.
